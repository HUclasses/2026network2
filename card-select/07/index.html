やること

  1. 学籍番号を入れる（自分の番号。例のまま入れない）。
  2. 下の構成図と目標を見て、実習でやる操作のカードを左の棚から選び、構成図の下の枠に入れる（ドラッグ。同じカードを何枚でも使える）。枠の番号がやる順番、枠の数がその機器に置くカードの数。設定のカードは機器の枠へ、確かめるカードは「確かめる」の枠へ。カードを入れると、コマンドのヒントが出る。
  3. 各カードに値（VLAN の番号・名前、ポート、IP アドレスなど）を書く。確かめる操作のカードは、どこからどこへ・何を見るかを書く。
  4. ステップ 3 のファイルの続きなので、もうできている設定のカードは置かない。
  5. 置き終えたら、その番号の順に Packet Tracer で設定する。このページ全体と、ブラウザの大学アカウント（メールアドレスが見える状態）を一緒に撮り、2024mXYZ_5.png として「第7回 スクリーンショット」に出す。

答え合わせはありません。スライドを見ずに、構成図と目標から自分で考えてください。値が 2 つある操作は、1 枚のカードに 2 つ書いてよい。画面に入りきらないときは、ブラウザの表示を縮小（Ctrl と −、Mac は ⌘ と −）してから撮ってください。
